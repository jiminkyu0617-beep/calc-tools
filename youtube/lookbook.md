# 룩북

**채널의 기억 2/3.** 이 채널이 어떻게 보이는지의 현재 기준선.
비주얼 디렉터가 매번 이걸 읽고 시작하고, 성과가 검증된 것만 여기로 승격된다.

> **룩은 10편 단위로 바꾼다. 편마다 바꾸지 않는다.**
> 매 편 다른 고급스러운 룩보다, 매 편 같은 평범한 룩이 채널을 만든다.

## 현재 기준선 (v1 — 001화에서 확정)

> **이 표는 설명이 아니라 코드다.** 실제 값은 `youtube/render/theme.css`에 있고,
> 렌더는 그 파일을 읽는다. 룩을 바꾼다는 건 그 파일을 고친다는 뜻이고,
> 그러면 다시 렌더하는 전 회차가 같이 바뀐다. 문서와 결과물이 어긋날 수 없다.

| 변수 | 스펙 | 확정도 |
|---|---|---|
| **색** | 배경 `#0B0D10` / 텍스트 `#F2F5F7` / 보조 `#8A96A3` / 강조 `#FF4D2E` / 축 `#232B35` | **확정** |
| **빛** | 광원 없음. 평면. 그림자·글로우 0 | **확정** |
| **질감** | 0. 그레인·블러 없음. **깨끗함이 이 채널의 룩이다** | **확정** |
| **타이포** | Pretendard (OFL). 숫자 tabular. 후킹 92px / 자막 64px / 축 34px / 주인공 숫자 150px | **확정** |
| **모션** | `ease.out = 1-(1-p)^5` 단일 곡선. 자막 등장 0.25s, 전환 0.3s. CSS 애니메이션 금지 | **확정** |
| **여백** | 상단 12% / 하단 20% 안전 영역, 좌우 72px, 화면당 정보 1개 | **확정** |

### 강조색 사용 규칙 (001화에서 한 번 어겼다가 잡음)
`--accent`는 **화면의 10% 이하**. 001화 초안에서 눈금자 전체를 강조색으로 칠했다가
QC에서 걸렸다. 지금 규칙은 이렇다.
- 눈금자 본체 → `--accent-dim`
- 현재 위치를 가리키는 헤드(작은 점), 결정적 숫자, 자막의 핵심 단어 **한 덩어리** → `--accent`
- 비교 막대에서 **강조 대상 쪽 하나만** `--accent`, 나머지는 `--grid`

## 원칙

1. **예쁜 것과 잘 보이는 것이 충돌하면 잘 보이는 쪽이 이긴다.** 6인치, 무음, 스크롤 중.
2. **강조가 화면의 10%를 넘으면 그건 배경색이다.**
3. **유행 전환 효과는 6개월 뒤 촌스러움의 원인이다.** 룩북에 없는 효과를 쓰려면 정당화가 필요하다.
4. **"영상 예쁘다" 댓글이 많은데 유지율이 낮으면 과잉 투자다.** 단순화도 비주얼 디렉터의 일이다.
5. **화면은 자막보다 먼저 거짓말을 한다.** 001화 초안에서 축은 12,262m 그대로 두고 헤드만
   1/3 지점으로 올렸더니 "4,000m밖에 못 팠다"로 읽혔다. 사실과 다른 화면이다.
   **축의 의미가 바뀌면 축의 라벨도 같이 바꾼다.** 이건 취향이 아니라 검수 사항이다.
