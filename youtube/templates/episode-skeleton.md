# 에피소드 파일 골격

새 회차 디렉터리 `youtube/episodes/<번호>-<슬러그>/`에 만들어지는 파일과 담당.

| 파일 | 담당 | 없으면 다음 단계 시작 금지 |
|---|---|---|
| `00-brief.md` | yt-strategist | |
| `01-scout.md` | yt-scout | G1 훅 게이트 |
| `02-script.md` | yt-scriptwriter | G2 대본 게이트 |
| `03-direction.md` | yt-director | |
| `04-visual.md` | yt-visual | G3 비주얼 게이트 (QC 섹션) |
| `05-edit.md` + `subtitles.srt` | yt-editor | |
| `06-packaging.md` | yt-packager | |
| `07-qa.md` | yt-reviewer | G4 검수 게이트 |
| `08-publish.md` | yt-showrunner | G5 발행 게이트 |
| `09-comments.md` | yt-community | |
| `10-report.md` | yt-analyst | |
| `11-revision.md` | yt-revisionist | G6 리비전 게이트 |

**루프를 닫는 마지막 작업**: 총괄 PD가 `hook-log.md`와 `lookbook.md`를 갱신한다.
이걸 안 하면 다음 편의 팀은 이번 편에서 배운 걸 모른다.
