# 계산모음 (calc-site) — 신규 사업 아이템 ①

`docs/strategy/new-business-ideas.md` 아이템 ①(생활·금융 계산기 사이트)의 실제 착수분이다.
정적 HTML/CSS/JS만 쓴다. LLM API 키가 없어도 100% 동작한다 — 이게 이 아이템을 1순위로
고른 이유다.

## 왜 퇴직금 계산기부터인가

`src/naver_datalab.py`로 후보 9개 상대수요를 실측했다(앵커: 연봉계산기, 6개월 평균).

```
대출이자 계산기      0.845
퇴직금 계산기        0.783   ← 착수
실업급여 계산기      0.300
4대보험 계산기       0.268
부가세 계산기        0.229
양도소득세 계산기     0.083
상속세 계산기        0.020
육아휴직급여 계산기   0.002
전세자금대출 한도    0.000
```

수요만 보면 "대출이자 계산기"가 근소하게 높지만 **퇴직금 계산기를 먼저 만들었다.**
이유는 두 가지다.

1. **계산식이 법(근로기준법 제2조·제34조)에 고정돼 있다.** 연 단위로 바뀌는 세율·요율
   테이블이 필요 없다 — 매년 갱신을 안 해도 계산이 틀리지 않는다.
2. **연봉 실수령액 계산기는 뒤로 미뤘다.** 정확하려면 국세청 간이세액표(소득 구간별
   원천징수액, 수천 행)와 그 해 4대보험 요율을 반영해야 한다. **이 요율을 실측
   확인하지 못한 채로 배포하면 신뢰도 문제가 바로 터진다** (`new-business-ideas.md`
   §2 리스크: "계산이 한 번 틀리면 사이트 전체 신뢰가 죽는다"). 요율 확인 후 공개한다.
3. "대출이자 계산기"는 원리금균등/원금균등 상환 방식 분기가 있고 이미 은행·금융감독원
   공식 계산기가 존재해 경쟁이 세다. 퇴직금은 고용노동부 계산기 외에 개인 사이트가
   상대적으로 적었다(비공식 관찰, 표본 수 조사는 안 함).

## 계산 방식 — 검증 필요 시 참고

```
평균임금 = (최근 3개월 급여 총액 + 연간상여금×3/12 + 연차수당×3/12) ÷ 그 3개월간 총일수
퇴직금   = 1일 평균임금 × 30 × (재직일수 ÷ 365)
```

**하지 않은 것 (v1 한계, 명시)**
- 통상임금과 평균임금 비교(더 큰 쪽 적용)를 하지 않는다 — 평균임금만 계산한다.
- 퇴직소득세 원천징수를 반영하지 않는다 — 세전 추정치다.
- 1년 미만 근속 시 경고만 띄우고 0원 처리는 하지 않는다(참고용 수치 그대로 보여줌).

## 두 번째로 부가세 계산기를 추가한 이유

퇴직금 계산기와 같은 기준(법에 고정된 계산식, 연도별 요율 테이블 불필요)으로
바로 만들 수 있는 것을 하나 더 찾았다. 부가가치세율 10%는 부가가치세법
제30조에 고정돼 있고 해마다 바뀌지 않는다 — 검증 없이 배포해도 되는
몇 안 되는 세금 계산이다. 상대수요는 0.229로 중간이지만, 착수 리스크가
거의 0이라 순서를 앞당겼다.
