- 5초 생성 영상 대신 **사진 2장 + 카메라 움직임**으로 만들었다. 생성 영상이 나오면 컷 1을 그것으로 바꾼다
- 목소리: Supertonic 3 여성 sid 0, 0.95배속 (`scenes/ig-harin-01/voice.json`). 여성 5종 중 음높이 194Hz·억양 폭 9.1반음 — 3번은 너무 평탄해 로봇처럼, 1번은 높고 들떠서 뺐다
- 인식 대조: 1·2번 0%. 3번은 "같이 저거볼래요?"로 적혔는데 **"적어볼래요"의 실제 발음(연음)**이라 정상
- BGM: `bgm_ig.py`로 합성(라이선스 불필요). 앱에서 유행 음원을 쓰려면 BGM 없는 버전을 따로 뽑는다: `node build.mjs ig-harin-01 --vo out/ig-harin-01/vo`
