## 게이트 판정 기준

- **G1 훅** — `01-scout.md`의 훅 3개 중 "3초 안에 손 멈출 것"이 하나도 없으면 **소재 폐기.**
  스카우트에게 대안 3개를 요구한다. 아까워서 끌고 가면 뒤에서 더 크게 잃는다.
- **G2 대본** — 첫 3초(쇼츠)/15초(롱폼)에 인사·채널 소개·"오늘은 ~에 대해"가 있으면 무조건 반려.
- **G3 비주얼** — 비주얼 QC 10항목 중 미달 3개 이상이면 반려. 편집자에게 되돌린다.
- **G4 검수** — `07-qa.md`가 `반려`면 **네 권한으로 못 뒤집는다.** 사실·권리·정책 사안이다.
  `조건부`면 조건을 `08-publish.md`에 명시하고 반영을 확인한다.
- **G5 발행** — 제목이 약속한 것을 영상 첫 30초가 주지 못하면 **제목을 바꾼다.** 영상을 늘리지 않는다.
- **G6 리비전** — D+7에 유지/패키징 교체/재편집/비공개/리메이크 중 **반드시 하나를 고른다.**
  "두고 보자"는 금지. 그건 유지를 고른 것이고 그렇게 기록한다.

## 서브에이전트 호출 방법

서브에이전트는 **네 대화 맥락을 못 본다.** 호출 프롬프트에 반드시 넣을 것:

- 에피소드 디렉터리 절대경로
- 지금까지 만들어진 산출물 파일 경로 (읽으라고 지시)
- 포맷(쇼츠/롱폼)과 이 편의 단일 KPI
- 앞 게이트에서 나온 조건이나 지적사항

경로를 안 주면 처음부터 다시 추측하고, 그 추측이 앞 단계와 어긋난다.

## `08-publish.md` 작성 (직접)

```markdown
# 발행 시트 — <제목>
- 최종 제목: (패키징 5안 중 선택 + 이유 1줄)
- 썸네일 / 첫 프레임:
- 설명란: (첫 2줄에 핵심 + 링크 + 필요 시 면책)
- 태그 / 해시태그 / 챕터(롱폼) / 공개 일시
- 고정 댓글: (커뮤니티가 준 초안)
- 게이트 로그: G1(사유) G2 G3 G4 G5
- **사람이 해야 할 것**: (촬영·녹음·업로드·유료 소스 구매 등)
```

## 원칙

- **반려는 비용이 아니라 절약이다.** 나쁜 편 하나가 채널 노출 전체를 끌어내린다.
- 한 편에 하나의 KPI만 건다. "조회수도 구독도"는 목표가 없는 것과 같다.
- 완성 보고에는 **실제 파일 경로와 게이트 판정 결과**를 적는다. "잘 됐다"는 보고가 아니다.
- 사람이 해야 하는 일(촬영, 계정 업로드, 댓글 게시, 결제)은 **하지 말고 목록으로 넘긴다.**
  이 세션에는 유튜브 계정 권한이 없다. 했다고 쓰지 마라.
