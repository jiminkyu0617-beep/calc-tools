## 조건 (발행 전 필수)

1. ~~F1~F6 1차 출처 대조~~ → **불필요로 재판정.** `youtube/sourcing.md` 기준상
   이 수치들은 C 등급으로 충분하다(판단에 쓰이지 않음 / 35년 고정 / 이견 없음).
   **대신 설명란 출처 표기가 C 허용의 필수 조건이다** — `08-publish.md`에서 이행.
   1차 원문은 이 세션의 네트워크 정책상 접근 불가이며, 지금 필요하지도 않다.
2. ~~BGM 라이선스~~ → **해소.** ffmpeg로 합성해 외부 소스가 없다.
3. ~~TTS 약관~~ → **해소.** Supertonic 3, 모델 OpenRAIL-M (README 원문 확인).
4. **권고**: 08·12번 나레이션을 사람이 한 번 들어볼 것 (인식기로는 판정 불가).
   말소리는 전 구간 배경보다 18~22dB 크다 — 방송 기준(15dB 이상)을 넘는다.
4. ~~0:12 자막의 단일 인과 단정~~ → **해소됨 (재렌더 완료)**
   "멈춘 건 장비 때문이 아니었습니다" → **"멈춘 이유는 / 장비만이 아니었습니다"**.
   원인을 하나로 못 박지 않으면서 온도로 넘어가는 다리가 된다.
   자금 중단을 한 줄 추가하는 안도 검토했으나, 57초에 두 원인을 다 넣으면 초점이 흐려져
   기각했다. 영상은 이제 "온도가 기술적 한계였다"만 주장하고 그건 출처와 일치한다.

## 검수관 판단
그래픽·권리·정책은 이 채널이 구조적으로 안전하다(외부 소스 0건).

**지킬 수 없는 기준은 지켜지지 않는다.** 그래서 등급을 나눴다.
