# 유튜브 에피소드 제작 파이프라인

인자로 받은 주제로 영상 한 편의 제작 문서 일체를 만든다.

## 실행

1. `youtube/channel-brief.md`와 `youtube/README.md`를 읽는다.
2. `youtube/episodes/`의 최대 번호 +1로 디렉터리를 만든다: `<3자리>-<영문슬러그>/`
3. **`yt-showrunner` 에이전트를 호출**해 파이프라인 전체를 맡긴다.
   프롬프트에 반드시 포함: 주제, 에피소드 디렉터리 절대경로, 포맷(쇼츠/롱폼) 지정 여부.
4. 총괄이 반환한 게이트 로그와 파일 목록을 사용자에게 보고한다.

## 인자가 없을 때

주제 없이 호출되면 `yt-researcher`를 먼저 돌려 소재 후보 8개를 받고,
**1순위 추천과 이유**를 제시한 뒤 사용자 선택을 기다린다. 임의로 정하지 않는다.

## 부분 실행

사용자가 특정 단계만 요청하면(예: "썸네일만 다시") 해당 에이전트만 호출하고,
그 산출물 파일만 갱신한다. 앞 단계 파일은 건드리지 않는다.

## 보고 형식

```
에피소드: youtube/episodes/003-unemployment-cap/
G1 기획 통과 — 9월 개정 고시 반영, 상위 3편 모두 상한액 미언급
G2 대본 통과 / G3 검수 조건부 (0:22 단정 어미 수정 반영 완료)
생성: 00-brief.md 01-research.md 02-script.md 03-direction.md
      04-edit.md subtitles.srt 05-packaging.md 06-qa.md 07-publish.md
사람이 해야 할 것: 계산기 화면 녹화 2컷, BGM 라이선스 확정, 업로드
```
