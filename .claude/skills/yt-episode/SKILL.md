# 에피소드 제작 파이프라인 (발행 전)

## 실행

1. `youtube/channel-brief.md`, `youtube/hook-log.md`, `youtube/lookbook.md`를 읽는다.
2. `youtube/episodes/`의 최대 번호 +1로 디렉터리 생성: `<3자리>-<영문슬러그>/`
3. **`yt-showrunner` 에이전트를 호출**해 파이프라인을 맡긴다.
   프롬프트에 반드시 포함: 주제, 에피소드 디렉터리 **절대경로**, 포맷(쇼츠/롱폼), 이 편의 단일 KPI.
4. 총괄이 반환한 게이트 로그와 파일 목록을 보고한다.

## 인자가 없을 때

`yt-scout`을 먼저 돌려 소재 후보 10개(각각 훅 한 줄 포함)를 받고,
**1순위 추천과 이유**를 제시한 뒤 사용자 선택을 기다린다. 임의로 정하지 않는다.

## 채널 브리프가 미확정일 때

`youtube/channel-brief.md`의 "결정해야 할 것"에 미정 항목이 있으면,
파이프라인을 강행하지 말고 **어떤 결정이 왜 필요한지** 사용자에게 먼저 묻는다.
특히 출연 형태(얼굴/목소리/무출연)가 미정이면 연출·비주얼 단계가 추측으로 채워진다.

## 부분 실행

"썸네일만 다시", "영상미만 다시" 같은 요청이면 해당 에이전트만 호출하고
그 산출물 파일만 갱신한다. 앞 단계 파일은 건드리지 않는다.

## 보고 형식

```
에피소드: youtube/episodes/003-deep-sea/
G1 훅 통과 — H2 "심해 3000m에서 그물을 올렸더니" (호기심 공백)
G2 대본 통과 / G3 비주얼 통과(QC 9/10) / G4 검수 조건부(0:22 단정 어미 수정 완료)
생성: 00~08 + subtitles.srt
사람이 해야 할 것: 나레이션 녹음, 소스 영상 2컷 확보, 업로드
```

발행 후에는 `/yt-feedback <회차>`로 루프의 나머지 절반을 돈다.
