# 출처 기준

**채널의 기억 5번째 파일.** 어떤 주장에 어느 등급의 출처가 필요한지를 정한다.

## 왜 이 파일이 필요한가

001화 검수에서 "출처가 전부 2차라 발행 보류"가 나왔다. 원칙은 맞지만 **기준이 너무 뭉툭했다.**
이대로면 모든 회차가 영원히 조건부가 되고, 그러면 팀은 검수 판정을 무시하게 된다.
**아무도 지킬 수 없는 규칙은 지켜지지 않는 규칙이다.**

그래서 등급을 나누고, **언제 엄격한 등급이 필요한지**를 정했다.
검수관은 이제 "2차니까 반려"가 아니라 "이 주장에 필요한 등급은 무엇인가"를 판정한다.

## 출처 등급

| 등급 | 정의 | 예 |
|---|---|---|
| **A · 1차** | 사건·측정의 당사자가 낸 기록 | 원 조사보고서, 학술 논문, 기관 공식 발표·고시, 법령, 특허 원문, 재판 판결문 |
| **B · 준1차** | 전문성이 검증된 2차 | 학회지 리뷰, 국가기관·국제기구 요약 자료, 저자와 근거가 명시된 전문 매체 |
| **C · 2차 교차** | 서로 독립된 일반 매체 **3곳 이상**이 같은 수치를 말함 | 일반 언론, 백과, 교양 매체 |
| **D · 미확인** | 단일 출처, 출처 없는 전언, 커뮤니티 | "~라고 한다" |

**D는 어떤 경우에도 영상에 들어가지 않는다.** 등급 논의의 대상이 아니다.

## 필요 등급 판정

두 가지만 묻는다. **틀렸을 때 누가 다치는가**, 그리고 **지금 논쟁 중인가.**

| 주장의 성격 | 필요 등급 |
|---|---|
| 시청자가 **돈·건강·법적 판단에 쓸** 수치 | **A 필수** |
| **최근 바뀌었거나 바뀔 수 있는** 수치 (요율, 세율, 기록, 순위, 가격) | **A 또는 B** |
| **출처마다 값이 다르거나** 논쟁 중인 수치 | **A 필수** |
| **통념 파괴형 주장의 핵심 근거** | **A 또는 B** — 재미의 크기와 검증 강도를 비례시킨다 |
| 특정 **개인·기업에 대한 부정적 사실** | **A 필수** — 명예훼손 영역이다 |
| 수십 년간 고정되고 **출처 간 이견이 없는** 역사적·물리적 수치 | **C 허용** |
| 우리가 직접 계산한 파생 수치 | 원 수치의 등급 + **검산 기록** |

### C를 허용할 때의 조건 (셋 다 충족해야 한다)
1. 서로 **독립된** 출처 3곳 이상이 같은 값을 말한다 (한 곳을 서로 베낀 것은 1곳이다)
2. 그 값에 **이견을 제기하는 출처가 없다**
3. **설명란에 출처를 적고, 화면에 근거를 식별할 표시를 둔다**
   (쇼츠에 각주를 띄우는 건 노이즈다. 화면은 무엇에 관한 기록인지만 밝히고,
   목록은 설명란이 진다)

## "출처를 적으면 되지 않나"에 대해

**저작권과 정확성은 다른 문제다.** 섞으면 위험하다.

| | 무엇을 해결하는가 | 우리 채널의 상태 |
|---|---|---|
| **재창조·출처 표기** | **저작권.** 남의 화면·글을 안 쓰거나, 인용 범위를 지킨다 | **이미 해결됨** — 외부 소스 0건, 모든 화면을 직접 그린다 |
| **출처 대조** | **정확성.** 그 숫자가 실제로 맞는가 | 별개로 해야 한다 |

설명란에 출처를 적어도 **숫자가 틀렸으면 영상은 틀린 영상이다.**
출처 표기는 "내가 어디서 봤는지"를 밝히는 것이지 "이게 맞다"의 근거가 아니다.
그리고 정정 댓글은 **이미 본 사람에게 닿지 않는다.** 조회수의 대부분은 첫 며칠에 나오고,
그 사람들은 댓글을 다시 보러 오지 않는다.

다만 **출처를 적는 것 자체는 해야 한다.** 정확성을 보장하진 않지만,
틀렸을 때 어디서 틀렸는지 추적할 수 있게 하고, 시청자가 직접 확인할 길을 준다.
이 채널의 톤(`channel-brief.md`: "모르는 것은 모른다고 말한다")과도 맞는다.

## 이 환경의 제약 (알고 있어야 한다)

이 세션에서는 **1차 출처 원문에 접근할 수 없다.** 네트워크 정책이 위키백과·ScienceDirect·
Scientific American·Britannica·USGS·Springer 등을 차단하고, 검색 요약만 돌아온다.

→ **A·B 등급이 필요한 주장은 사람이 확인해야 한다.** 에이전트가 대신 못 한다.
→ 검수관은 A·B가 필요한 항목을 **"사람 확인 필요"로 명시**하고 넘긴다. 혼자 통과시키지 않는다.
