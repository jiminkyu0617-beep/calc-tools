## 1. 영상이 실제로 한 것

**실험 규칙**: 전체 비용 99달러 미만 / 본인 얼굴·목소리 사용 금지 / 첫 AI 인플루언서는 당일 완성.
7일 안에 1,000달러를 못 벌면 댓글 한 명에게 1,000달러를 준다.

| 단계 | 내용 |
|---|---|
| 주제 선정 | 돈 되는 주제로 **건강·돈·관계**를 골랐다. 돈을 말하는 AI 계정이 없어서 그 빈칸을 노렸다 |
| 분산 | 한 계정에 걸지 않고 **주제마다 1개씩 3개 계정**(아모스·시에나·비비안)을 동시에 열었다 |
| 제작 도구 | 캐릭터·프롬프트·판매 상품은 **Claude 무료 요금제**, 사진·영상은 **Higgsfield를 Claude에 커스텀 커넥터로 연결**해 한 채팅에서 생성 |
| 배포 | **인스타그램만.** 계정마다 영상 10개씩 올린 뒤 승자를 고른다 |
| 수익화 | 브랜드 계약(느림)·실물 판매(상점 운영이 일)·릴스 광고(수익 없음)·틱톡 샵(틱톡 미게시)을 제외하고 **디지털 워크북**을 팔았다. 전자책은 검색·ChatGPT로 공짜가 되니, 매일 채우며 변화를 기록하는 30일 워크북으로 |
| 판매 | Stan Store(14일 무료 체험)에 올림 |

**결과 (7일)**: 워크북 23개 × 12달러 = 매출 276달러 − 페이팔 수수료 19.52달러 − Higgsfield 99달러
= **순이익 약 157달러.** 목표 1,000달러 미달.

**관찰**:
- 초반 1위는 아모스였는데, 늦게 비비안 영상이 1만 → 2만 → **25만 조회**로 커졌다. 7일은 판단하기에 짧다
- 시청자는 시에나가 AI인 줄 모르고 옷·음료로 댓글 싸움을 했다. 나중에 AI라고 밝혔고 항의 댓글은 없었다고 한다
- 제작자 본인의 유보: **"전부 AI면 실제 사람과 연결되는 맛이 빠진다."** "AI 슬롭"을 언급했다

1. **이 영상은 Higgsfield 협찬 광고다** (할인 코드 TILBURY). "가장 게으른 방법"은 광고 프레이밍이다.
2. **195만 조회는 마크 틸버리 본인 채널(실제 얼굴·기존 구독자)의 조회수다.** AI 인플루언서 계정의 성과가 아니다.

5. **유튜브**는 2025-07 비진정성 콘텐츠 정책으로 대량·템플릿형 AI 영상의 수익화를 막는다 (`open-source-stack.md`).

## 3. 핵심 구조 — "Claude는 두뇌, 생성기는 손, 커넥터가 신경"

```
 [사람] ─명령─▶ [Claude] ─커넥터(MCP)─▶ [이미지·영상 생성기]
                 기획·캐릭터·프롬프트·       사진·영상을 실제로 만든다
                 대본·캡션·판매 상품
```

샘플의 방식은 **Claude 채팅 하나에서 기획부터 생성까지** 끝내는 것이다.
그러려면 생성기가 **Claude에 커넥터로 연결되는 서비스**여야 한다.
커스텀 커넥터(원격 MCP)는 **Claude 무료 요금제에서도** 쓸 수 있다.
연결은 https://claude.ai/customize/connectors 에서 하고, **새 채팅을 열어야** 적용된다.

## 4. Higgsfield(월 99달러) 대신 쓸 수 있는 것

| 방식 | 비용 | Claude 한 채팅 연결 | 수익화(상업 이용) | 판정 |
|---|---|---|---|---|
| **ComfyUI + Comfy MCP** (내 PC) | **0원** | ✅ Claude 데스크톱 앱에 연결 | 모델 라이선스에 따름 (아래) | **NVIDIA GPU(VRAM 8~12GB 이상)가 있으면 1순위** |
| ComfyUI on Kaggle/Colab 무료 GPU | **0원** | ❌ 연결이 번거로움 → Claude가 쓴 프롬프트를 복사해 넣는 방식 | 모델 라이선스에 따름 | GPU가 없을 때의 무료 경로 |
| Imagine (MCP 서비스) | 하루 약 100크레딧 무료 (블로그 기준) | ✅ claude.ai 커넥터 | **약관 확인 필요** | 연습용 |
| Kling / Hailuo 무료 요금제 | 무료 크레딧 | ❌ | **❌ 워터마크 + 상업 이용 금지** | 수익화에는 못 쓴다 |
| Kling Standard 등 최저 유료 | 월 약 7~10달러 | ❌ (복사해 넣기) | ✅ | Higgsfield의 1/10 가격 |
| Replicate / fal.ai | 쓴 만큼 과금 | fal은 claude.ai 커넥터 미지원(OAuth) → Claude Code·데스크톱 | 모델별 | 소량이면 가장 쌀 수 있다 |

## 5. Claude에게 이렇게 명령한다 (복사해서 쓰는 명령문)

샘플의 7일 흐름을 그대로 따른다. `[ ]` 안만 바꿔 쓴다.
**한 채팅에 한 단계씩**, 앞 단계 결과를 붙여 넣으며 진행하면 흐름이 안 꼬인다.

### 0단계 — 연결 (1회)
1. https://claude.ai/customize/connectors 에서 생성기 커넥터 추가
   (ComfyUI를 쓰면 Claude 데스크톱 앱의 설정에 Comfy MCP를 추가)
2. **새 채팅**을 연다 (커넥터는 채팅을 시작할 때 읽힌다)
3. 확인 명령: `연결된 도구 목록을 보여주고, 이미지 1장을 시험 생성해줘.`

### 1단계 — 주제와 수익 구조
```
너는 인스타그램 AI 인플루언서 사업 전략가야.
조건: 예산 [99달러] 이하, 내 얼굴·목소리 없음, [한국어] 시장, 판매 상품은 디지털 상품.
돈이 되는 주제 후보 5개를 [건강/돈/관계] 중심으로 제시하고,
각각 ① 이미 있는 AI 계정의 빈칸 ② 팔 수 있는 디지털 상품 ③ 첫 7일 성공 기준을 표로 줘.
마지막에 동시에 시험할 3개를 골라 이유를 한 줄씩 써줘.
```

### 2단계 — 캐릭터 설계서 (가장 중요)
```
위 3개 주제마다 인플루언서 1명씩 캐릭터 설계서를 만들어줘.
항목: 이름, 나이, 국적·외모(얼굴형·머리·눈·피부·체형을 구체적으로),
옷 스타일 3벌, 사는 곳·배경 장소 3곳, 말투, 성격, 게시물 톤, 금지 사항.
외모는 매번 똑같이 재현할 수 있도록 "고정 외모 문장" 한 단락으로 따로 써줘.
```
> **"고정 외모 문장"이 캐릭터 일관성의 핵심이다.** 모든 생성 명령에 이 문장을 그대로 붙인다.

### 3단계 — 기준 이미지 (캐릭터 시트)
```
[캐릭터 이름]의 고정 외모 문장으로 캐릭터 기준 이미지를 만들어줘:
정면 얼굴, 3/4 측면, 전신. 배경은 단색, 조명은 자연광.
사실적인 사진 스타일, 세로 9:16.
```
> 이 기준 이미지를 이후 모든 생성의 **참조 이미지**로 쓴다. 얼굴이 흔들리는 걸 막는다.

### 4단계 — 첫 10개 콘텐츠 기획
```
[캐릭터 이름]으로 인스타그램 릴스 10개를 기획해줘.
각 편마다: 첫 1초 장면(스크롤을 멈추게 할 것), 5~8초 영상 설명, 화면 자막 한 줄,
캡션, 해시태그 5개, 댓글을 부르는 질문 하나.
10편 중 3편은 논쟁을 부르는 주제(예: 옷·음료 선택)로 넣어줘.
```

### 5단계 — 생성 (커넥터 사용)
```
4단계의 1번 편을 만들어줘.
기준 이미지를 참조해서 얼굴을 유지하고, 고정 외모 문장을 그대로 넣어.
먼저 첫 장면 이미지 1장을 만들고 내가 확인하면 5초 영상으로 움직여줘.
```
> **이미지 먼저 → 확인 → 영상** 순서를 지킨다. 영상이 더 비싸고 느리다.

### 6단계 — 올리기 전 점검
```
이 게시물이 인스타그램 AI 규정에 맞는지 점검해줘:
AI 생성 인물 프로필 라벨, 게시물 AI 표시, 캡션에 AI임을 밝히는 문장.
빠진 게 있으면 추가 문구를 써줘.
```

### 7단계 — 판매 상품
```
[주제]로 30일 워크북을 만들어줘. 매일 5분 안에 채울 수 있는 칸,
주간 점검표, 30일 전후 비교 페이지를 넣고, 판매 페이지 문구(제목·3줄 설명·가격 제안)도 써줘.
```

### 8단계 — 성과 보고 → 다음 수
```
3개 계정의 지난 [3]일 지표야: [조회수/좋아요/댓글/팔로워/판매 붙여넣기]
어느 계정에 집중할지, 어떤 편이 왜 먹혔는지, 다음 10편에서 바꿀 것 딱 하나를 알려줘.
단, 7일은 짧다는 걸 감안해서 늦게 오르는 편도 표시해줘.
```

## 6. 우리 채널(한계선)에 적용하면

사장님 지적: **"움직이는 그림이 없고 어색한 부분이 있다."** 맞다. 지금은 도해만 움직인다.
두 갈래가 있다.

| | A. 한계선 유지 + 움직이는 그림 보강 | B. 샘플처럼 AI 인플루언서 |
|---|---|---|
| 무엇 | 추상 컷(암석 변형·심해·용암 질감)을 생성해 도해 사이에 넣는다 | 가상 인물 계정을 만들어 인스타그램 운영 + 디지털 상품 판매 |
| 플랫폼 | 유튜브 쇼츠 | 인스타그램 |
| 규칙 | `generative-policy.md` — 숫자·도해는 코드, 질감·현상만 생성 | AI 인물 라벨 필수 (2026-08-31~) |
| 위험 | 낮음 (외부 소스 0건 유지) | 인물 라벨로 도달 감소 가능, AI 슬롭 리스크 |
| 이 작업 환경에서 | 생성은 사장님 PC·무료 GPU에서, 합성은 여기서 | Claude 채팅(claude.ai)에서 직접 |

둘은 배타적이지 않다. **A는 이 채널의 개선**, **B는 별도 사업 실험**이다.
