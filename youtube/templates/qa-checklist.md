# 발행 전 검수 체크리스트

## 사실
- [ ] 모든 수치가 `01-research.md` 표에 근거가 있다
- [ ] 연도가 붙는 수치(요율·세율·상한액)에 **기준 연도**가 명시돼 있다
- [ ] 대본 숫자와 레포 계산기(`calculators/*.html`) 상수가 일치한다
- [ ] 모든 산식을 검수관이 직접 재계산했다

## 표현
- [ ] 확정 아닌 것에 확정 어미("받습니다")를 쓰지 않았다
- [ ] 개별 세무·법률 자문으로 읽힐 표현이 없다
- [ ] "못 하는 계산"을 영상에서 명시했다

## 권리
- [ ] BGM·폰트·이미지·영상 소스에 라이선스가 전부 기재됐다
- [ ] 출처 불명 소스 0건
- [ ] 생성 이미지가 실존 인물·기관 로고·실제 공문서를 흉내 내지 않는다
- [ ] 개인정보·실제 고지서 원본 노출 없음

## 정책·정직성
- [ ] 면책 문구 노출 (쇼츠 하단 상시 / 롱폼 오프닝 + 설명란)
- [ ] 제목이 약속한 것을 첫 30초 안에 제공한다
- [ ] 썸네일 숫자와 본문 숫자가 일치한다
- [ ] 특정 금융상품 추천·절세 꼼수 없음

## 기술
- [ ] 자막이 상단 12% / 하단 20% 안전 영역을 침범하지 않는다
- [ ] 오디오 -14 LUFS
- [ ] `subtitles.srt` 타임코드가 대본과 일치한다

**판정: PASS / 조건부(조건 명시) / 반려(사유 명시)**
