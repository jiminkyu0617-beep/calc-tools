# 05 편집 지시서 — 가장 깊은 구멍

> **이 편에는 전통적인 편집 공정이 없다.** 타임라인이 곧 코드다.
> 컷·자막·모션이 전부 `scenes/001-deepest-hole/scene.html`의 `render(t)` 하나에서 나온다.
> 편집 지시서를 고치는 게 아니라 씬을 고치고 다시 렌더한다.

## 렌더 명령
```bash
cd youtube/render
npm install                      # 최초 1회
node capture.mjs 001-deepest-hole # 1710 프레임 PNG
node build.mjs   001-deepest-hole # 무음 MP4
node build.mjs   001-deepest-hole vo.wav   # 나레이션 포함 (-14 LUFS 자동 정규화)
```

## 산출물 규격 (실측)
| 항목 | 값 |
|---|---|
| 길이 | 57.00초 |
| 해상도 | 1080×1920 |
| 프레임레이트 | 30 fps (1710 프레임) |
| 코덱 | H.264 High, yuv420p, CRF 18 |
| 파일 크기 | 892 KB (무음) |
| 오디오 | 없음 — 나레이션 대기 |

## 자막
번인 자막이 씬 안에 있다. `CAPTIONS` 배열이 원본이다.
**업로드용 `.srt`는 그 배열에서 생성한다** — 손으로 옮겨 적으면 타임코드가 어긋난다.

## 확보 필요 소스
| 소스 | 방법 | 라이선스 | 상태 |
|---|---|---|---|
| 모든 그래픽 | 자체 코드 렌더 | 자체 제작 | **완료** |
| Pretendard | npm `pretendard` | **OFL** (재배포·임베딩 가능) | 완료 |
| 나레이션 `vo.wav` | AI TTS, 보이스 1종 고정 | 서비스 약관 확인 필요 | **사람 필요** |
| BGM | 저음 드론 | **미확정 — 검수 조건** | **사람 필요** |
| SFX 3종 | 카운트업 정지 / 원 열림 / 축 전환 | 미확정 | **사람 필요** |

**외부 영상·이미지 소스 0건.** 저작권 리스크가 구조적으로 없다.
