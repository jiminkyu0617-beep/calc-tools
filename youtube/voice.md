# 나레이션 보이스 결정

**채널의 기억 4번째 파일.** 보이스는 룩만큼이나 채널 정체성이다.
**한 번 정하면 바꾸지 않는다.** 편마다 목소리가 다르면 시청자가 채널을 못 알아본다.

## 결정: 보이스 성격을 먼저 고정하고, 그 조건에 맞는 상품을 고른다

서비스보다 **보이스의 성격**이 먼저다. 서비스는 갈아탈 수 있지만 성격이 흔들리면 채널이 흔들린다.

### 보이스 스펙 (확정)

| 항목 | 값 | 이유 |
|---|---|---|
| 성별·연령 | **남성, 30~40대** | 이 채널의 소재는 실패와 한계다. 차분한 저음이 그 톤에 맞는다 |
| 톤 | **낮고 건조하게. 무감정에 가깝게** | `channel-brief.md` 톤 규칙: 감탄사 대신 수치로 말한다 |
| 속도 | **표준의 0.9~0.95배** | 숫자를 읽는 채널이다. 빠르면 숫자가 안 박힌다 |
| 억양 | **평탄하게.** 문장 끝을 올리지 않는다 | 올리면 광고 톤이 된다 |
| 강조 | **없음.** 강조는 화면이 한다 | 목소리까지 세면 과해진다 |

### 피할 것
- **뉴스 앵커 톤** — 과장돼 있고, 이 채널이 하지 않는 "충격/소름" 화법과 붙는다
- **밝고 친근한 톤** — 소재가 실패인데 목소리가 밝으면 어긋난다
- **감정 연기형 보이스** — 자막이 본문인 채널에서 연기는 방해다

### 핵심 원칙
**이 채널에서 나레이션은 주연이 아니다.** 자막이 본문이고, 시청자는 소리를 끄고 본다.
목소리는 **소리를 켠 사람에게만 주는 보조 트랙**이다.
그래서 좋은 보이스의 기준은 "매력적인가"가 아니라 **"화면을 방해하지 않는가"**다.
지루할 정도로 담백한 게 맞다.

## 서비스: **타입캐스트 베이직** (1순위)

| | 타입캐스트 | 클로바 더빙 | Higgsfield (이 세션) |
|---|---|---|---|
| 한국어 품질 | 좋음 | **최상** | 미검증 (한국어 프리셋 없음) |
| 상업적 이용 | 유료 플랜에서 허용 | 유료 플랜에서 허용 (무료는 비상업용 한정) | 확인 필요 |
| 보이스 선택폭 | **국내 최다** | 적음 | 영어권 프리셋만 |
| 비용 | 월 9,900원 / 60분 | 플랜별 상이 | 라인당 0.3 크레딧 |

→ **타입캐스트 베이직을 1순위로 고른다.**
- 주 2~3편 × 편당 1분 = **월 최대 13분.** 60분 플랜이면 재녹음 여유까지 충분하다.
- 보이스 선택폭이 넓어 위 스펙에 맞는 목소리를 실제로 찾을 가능성이 가장 높다.
  스펙이 까다로운 게 아니라 **평범한 목소리를 찾는 게 의외로 어렵다.**
- 무료 플랜은 워터마크가 들어가 쓸 수 없다. 유료로 시작한다.

→ **2순위: 클로바 더빙 유료.** 한국어 자연스러움은 여기가 낫다는 평가가 많다.
타입캐스트에서 위 스펙에 맞는 목소리를 못 찾으면 넘어간다.

> **위 표는 2차 출처(벤더 블로그 포함) 기준이며 가격·약관은 바뀐다.**
> **결제 전에 해당 서비스의 이용약관에서 유튜브 수익화 허용 여부를 직접 확인할 것.**
> 이건 `07-qa.md` 조건 3이고, 검수관이 발행 전에 다시 묻는다.

## Higgsfield를 쓰지 않는 이유
이 세션에 붙어 있어 바로 쓸 수 있지만 두 가지가 막는다.
1. **크레딧 0** (무료 플랜). 라인당 0.3 크레딧이라 편당 약 4.2 크레딧이 든다.
2. **한국어 프리셋 보이스가 없다.** 영어권 프리셋으로 한국어를 읽히는 건 도박이다.
   채널의 목소리를 도박으로 정하지 않는다.

크레딧을 충전하면 테스트해 볼 수는 있다. 다만 **1순위가 되긴 어렵다.**

## 워크플로 (보이스가 정해진 뒤)

```bash
cd youtube/render
node vo.mjs 001-deepest-hole      # 나레이션 대본 + 타임코드 명세 생성
```

`scenes/001-deepest-hole/narration.txt`의 각 줄을 TTS에 넣고,
결과를 `01.wav … 14.wav`로 한 디렉터리에 저장한 뒤:

```bash
node build.mjs 001-deepest-hole --vo <그 디렉터리>
```

**나레이션을 한 통으로 뽑지 않는다.** 줄 단위로 뽑아 각자의 시각에 꽂는다.
한 통으로 뽑으면 화면 타이밍과 반드시 어긋나고, 어긋나면 화면을 다시 맞춰야 한다.
`vo.mjs`가 각 줄이 자기 구간에 들어가는지 미리 검사한다 — 001화에서 실제로 두 줄이 걸려서
씬을 57초에서 59초로 늘렸다.

## TTS 녹음 설정
- 포맷: WAV, 48kHz, 모노
- 레벨 정규화는 하지 마라. `build.mjs`가 -14 LUFS로 맞춘다
- 문장 앞뒤 무음은 최소로. 클립 시작이 곧 발화 시작이어야 한다
