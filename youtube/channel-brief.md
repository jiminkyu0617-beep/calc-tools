# 채널 브리프

> 이 파일이 팀 전체의 단일 기준점이다. 니치를 바꾸려면 **이 파일만** 고친다.
> 에이전트 정의(`.claude/agents/yt-*.md`)에는 니치를 하드코딩하지 않았다.

## 채널 정체성

- **채널명(가안)**: 계산모음 — "돈으로 돌려받는 법"
- **한 줄 정의**: 내 월급·세금·정부지원금에서 **지금 당장 받아낼 수 있는 돈**을 숫자로 계산해 준다.
- **차별점**: 말로 설명하는 채널은 많다. 이 채널은 **화면에서 실제로 계산기를 돌려 숫자를 낸다.**
  (`https://jiminkyu0617-beep.github.io/calc-tools/` 의 계산기가 그대로 영상 소재다.)

## 왜 이 니치인가

1. **검색 수요가 계절마다 확정적으로 발생한다.** 연말정산(1월), 재산세(7·9월),
   종합소득세(5월), 퇴사 시즌(연중) — 소재 고갈이 구조적으로 안 일어난다.
2. **레포에 이미 검증된 원자재가 있다.** 계산기 9종 + 티스토리 해설 글이
   `README.md`에 법령 근거까지 정리돼 있다. 각본가는 무에서 시작하지 않는다.
3. **자산이 서로를 밀어준다.** 영상 → 계산기 페이지 → 블로그 글 → 다시 영상.
4. **광고 단가가 높은 주제다.** 금융·세무 키워드는 CPM이 높아 같은 조회수에서 수익이 크다.

## 타깃 시청자

- **1순위**: 25~45세 직장인. "퇴사하면 실업급여 얼마 나오지", "내 월급에서 왜 이만큼 떼가지"
- **2순위**: 40~60대 자산 보유자. 재산세·양도세·건강보험료
- 시청 맥락: 출퇴근길 세로 화면, 소리 없이 자막으로 본다 → **자막이 본문이다.**

## 콘텐츠 필러 (4종)

| 필러 | 목적 | 포맷 | 예시 |
|---|---|---|---|
| **A. 계산 실연** | 채널의 본체 | 쇼츠 45~60초 | "월급 300만원, 4대보험 얼마 떼가나" 화면에서 직접 입력 |
| **B. 시즌 대응** | 검색 유입 | 롱폼 6~10분 | "9월 재산세 고지서 보는 법" |
| **C. 오해 격파** | 저장·공유 유발 | 쇼츠 30~45초 | "퇴직금은 세전 급여 기준이 아닙니다" |
| **D. 사례 추적** | 구독 전환 | 롱폼 8~12분 | "3년차 퇴사자의 실업급여 8개월 전액 추적" |

발행 비율 기준선: A 40% / C 30% / B 20% / D 10%. 분석가가 분기마다 재조정한다.

## 톤앤매너

- **하는 것**: 숫자를 먼저 보여준다. 근거 법령을 화면 구석에 항상 띄운다. 못 하는 계산은 못 한다고 말한다.
- **안 하는 것**: 공포 마케팅("이거 모르면 손해 봅니다" 남발), 확정 아닌 수치를 확정처럼 말하기,
  개별 세무·법률 상담으로 읽힐 조언.
- 레포 `README.md`의 설계 원칙 3번("못 하는 것은 페이지에 명시한다")을 **영상에도 그대로 적용**한다.
  이게 이 채널의 신뢰 자산이고, 경쟁 채널이 못 따라오는 지점이다.
