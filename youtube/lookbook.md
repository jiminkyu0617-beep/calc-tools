# 룩북

**채널의 기억 2/3.** 이 채널이 어떻게 보이는지의 현재 기준선.
비주얼 디렉터가 매번 이걸 읽고 시작하고, 성과가 검증된 것만 여기로 승격된다.

> **룩은 10편 단위로 바꾼다. 편마다 바꾸지 않는다.**
> 매 편 다른 고급스러운 룩보다, 매 편 같은 평범한 룩이 채널을 만든다.

## 현재 기준선 (v0 — 미확정)

| 변수 | 스펙 | 확정도 |
|---|---|---|
| **색** | 배경 / 주조 / 강조 3색. 강조는 화면의 10% 이하 | 미정 |
| **빛** | 광원 방향·경도, 그림자 유무, 노출 기준 | 미정 |
| **질감** | 그레인·블러·글로우 강도. **0도 선택이다** | 미정 |
| **타이포** | 서체 1~2종, 자막 크기·자간·행간, 숫자는 tabular figures | 미정 |
| **모션** | 이징 곡선, 전환 프레임 수, 금지 효과 | 미정 |
| **여백** | 상단 12% / 하단 20% 안전 영역, 화면당 정보 1개 | **확정** |

## 원칙

1. **예쁜 것과 잘 보이는 것이 충돌하면 잘 보이는 쪽이 이긴다.** 6인치, 무음, 스크롤 중.
2. **강조가 화면의 10%를 넘으면 그건 배경색이다.**
3. **유행 전환 효과는 6개월 뒤 촌스러움의 원인이다.** 룩북에 없는 효과를 쓰려면 정당화가 필요하다.
4. **"영상 예쁘다" 댓글이 많은데 유지율이 낮으면 과잉 투자다.** 단순화도 비주얼 디렉터의 일이다.
