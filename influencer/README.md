# AI 인플루언서 실험 (B안)

Mark Tilbury의 7일 실험(`youtube/sample-tilbury-analysis.md`)을 **한국 인스타그램**에 맞게 옮긴 설계.
유튜브 채널 "한계선"(A안)과는 **별개의 사업 실험**이다.

## 샘플과 다르게 가는 것 세 가지

| | 샘플 (2026-09 이전) | 우리 |
|---|---|---|
| AI 표시 | 처음엔 숨겼다가 나중에 밝힘 | **첫 게시물부터 표시.** 인스타그램이 2026-08-31 "AI 생성 인물" 프로필 라벨을 도입했다. 안 달면 도달 감소·추천 제외 |
| 캐릭터 정체성 | 명시 안 됨 | **가짜 자격 금지.** 은행원·트레이너·상담사로 설정하지 않는다. 전문가인 척하는 AI는 신뢰 문제이자 규정 위험이다 |
| 조언 수위 | — | **개인 기록 톤.** "이렇게 하세요"가 아니라 "나는 이렇게 해봤다". 투자·의학 조언은 하지 않는다 |

## 계정 3개 (주제마다 하나 — 샘플과 같은 분산)

| 주제 | 캐릭터 | 콘셉트 | 파는 것 |
|---|---|---|---|
| **돈** | **하린** (29) | 월급날 다음 날부터 30일 지출을 기록하는 사회초년생 | **30일 지출 리셋 워크북** ← 첫 상품 |
| 건강 | 도윤 (34) | 하루 5분 루틴을 30일 지키는 직장인 | 30일 5분 루틴 체크북 (2차) |
| 관계 | 세아 (31) | 연락·대화 습관을 30일 기록하는 사람 | 30일 대화 일기 (2차) |

**돈을 첫 상품으로 고른 이유**: 샘플이 본 빈칸(돈을 말하는 AI 계정이 없다)이 한국에도 있고,
이 저장소의 **계산모음 사이트**(급여·세금·4대보험 계산기)와 바로 이어진다.
워크북 첫 장에서 실수령액을 계산기로 확인하게 해, 상품이 사이트 유입을 만든다.

## 7일 운영 계획

| 일차 | 할 일 |
|---|---|
| 0 | 계정 3개 개설, **AI 생성 인물 라벨** 켜기, 소개글 등록 (`characters/*.md`) |
| 1~5 | 계정마다 하루 2편씩 릴스 게시 (`content/*.md`의 10편) |
| 3 | 워크북 판매 페이지 공개 (`product/`) — 하린 계정 소개 링크 |
| 5 | 중간 점검: 조회·저장·댓글로 1위 계정 판정 → 거기에 집중 |
| 7 | 결산. **7일은 판단하기 짧다** — 샘플에서도 3위 계정이 뒤늦게 25만 조회를 냈다 |

## 성공 기준 (7일)
- 릴스 1편 이상 조회 1만
- 워크북 10부 판매
- AI 표시 관련 항의·신고 0건

## 파일
- `characters/` — 캐릭터 설계서 (고정 외모 문장, 소개글, 금지 사항)
- `content/` — 계정별 릴스 10편 기획 + 생성 프롬프트
- `product/30일-지출-리셋-워크북.pdf` — **실제 판매용 A4 14쪽** (원본 `workbook.html`, 재생성: `youtube/render/pdf.mjs`)
- `product/sales-page.md` — 판매 페이지 문구, 가격, FAQ
- `profile-mock.png` — 세 계정 인스타그램 프로필 미리보기 (AI 라벨·소개글·릴스 표지 9개, 캐릭터 사진 자리는 비움)

## 막혀 있는 것: 캐릭터 사진·영상

이 작업 환경은 GPU가 없고 AI 모델 저장소(HuggingFace)가 막혀 있어 **사진 같은 인물 이미지를 만들 수 없다.**
`content/*.md`의 생성 프롬프트는 준비돼 있다. 푸는 방법은 셋이다.

1. **이 환경의 네트워크 설정에서 `huggingface.co` 허용** → 여기서 CPU로 생성 (느리고 품질은 중간)
2. **claude.ai에 무료 크레딧이 있는 이미지 생성 커넥터 연결** → 프롬프트를 그대로 붙여 넣기 (약관의 상업 이용 조건 확인)
3. **월 7~10달러 유료 요금제**(Kling Standard 등) → 상업 이용 가능, 영상까지
