# 리비전 결정표

D+7에 회차마다 **반드시 하나를 고른다.** "두고 보자"는 유지를 고른 것이다.

| 증상 | 결정 | 실행 |
|---|---|---|
| 노출 많음 + CTR 낮음 | **패키징 교체** | 2순위 제목으로 교체 → 48h 관찰 → 안 되면 썸네일 |
| CTR 높음 + 3초 이탈 | **패키징 교체** | 제목이 과장했다. 약속을 낮춘 제목으로 |
| 특정 구간 급락 (5초 내 10%p+) | **재편집** | 초기 실적 낮을 때만. 중앙값 30% 넘겼으면 하지 않는다 |
| 전 구간 완만한 하락 | **유지** | 정상이다. 손대지 않는다 |
| 끝까지 봤는데 구독 없음 | **유지** + 다음 편 수정 | 이 편의 문제가 아니라 시리즈 부재의 문제 |
| 사실 오류 발견 | **고정 댓글 정정** 먼저 | 심각한 경우만 비공개 |
| 권리 항의 접수 | **즉시 비공개** | 사람이 판단할 때까지 |
| 소재는 옳았는데 실행 실패 | **리메이크** | 훅 로그상 해당 유형이 승리 패턴일 때만 |

## 관찰 규칙

- **한 번에 하나만 바꾼다.** 둘을 동시에 바꾸면 뭐가 효과였는지 영영 모른다.
- 변경 전 48h vs 변경 후 48h를 **같은 길이 구간으로** 비교한다.
- 결과를 반드시 `11-revision.md`에 기입한다. 안 그러면 다음에도 감으로 수정한다.

## 재업로드 판단선

이미 붙은 조회수·댓글·공유는 재업로드하면 사라진다.
**조회수가 채널 중앙값의 30%를 넘겼으면 재업로드하지 않는다.** 그건 개선이 아니라 파괴다.
