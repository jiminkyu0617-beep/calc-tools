## 설계 원칙

1. **계산식을 페이지에 그대로 공개한다.** 결과만 던지지 않고 단계별 중간값(과세표준, 공제액,
   적용 세율)을 표로 보여준다. 사용자가 검산할 수 있어야 신뢰가 생긴다.
2. **연 단위로 바뀌는 수치는 스크립트 상단에 상수로 모아둔다.** 요율이 바뀌면 그 줄만 고친다.
3. **못 하는 것은 페이지에 명시한다.** 예: 양도소득세 계산기는 2년 미만 단기 중과세율과
   1세대 1주택 비과세를 반영하지 않는다 — 이걸 숨기면 틀린 숫자를 맞다고 믿게 만든다.
4. **모든 페이지 하단에 "정확한 금액은 공식 기관 확인" 안내를 넣는다.**

## 검증

배포 전 아래를 실측 대조했다.

- 각 계산기의 예시 입력값을 해설 글에 실린 계산 결과와 대조 (실업급여·연차수당·4대보험·
  통상임금·퇴직소득세·양도소득세 전 항목 일치).
- 누진세율 구간 경계(1,400만/5,000만/8,800만/1.5억/3억/5억/10억)에서 세액이 튀지 않는지 확인.
- 재산세 특례·표준세율 구간 경계(6천만/1.5억/3억)에서 연속성 확인.
- `getElementById` 참조 id가 전부 HTML에 존재하는지 정적 검사.

**발견해 고친 버그**: 4대보험 계산기에서 `3,000,000 × 0.009`가 부동소수점 오차로
26999.999...가 되어 10원 절사 후 **26,990원**으로 표시되던 문제. `Math.round`를 먼저
걸어 27,000원으로 수정했다.
