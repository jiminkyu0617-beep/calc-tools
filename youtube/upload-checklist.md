# 업로드 체크리스트

**중요: 이 세션에는 유튜브 게시 도구가 없다.** (TikTok 게시 도구는 있으나 YouTube는 없음)
계정 로그인과 업로드는 **사람이 직접** 한다. 에이전트는 **올릴 것을 완성해서 넘기는 데까지**다.

---

## 1. 사람만 할 수 있는 것

| # | 항목 | 왜 대신 못 하는가 |
|---|---|---|
| 1 | **유튜브 업로드** | 게시 도구·계정 권한 없음 |
| 2 | **결제** (TTS 구독, BGM 라이선스) | 결제 수단 접근 없음 |

| 4 | **1차 출처 원문 열람** | 네트워크 정책이 학술·백과 사이트를 차단 |

4번은 `youtube/sourcing.md` 기준상 **A·B 등급이 필요한 회차에서만** 문제가 된다.

## 2. 파일로 주시면 제가 처리합니다

| 파일 | 형식 | 넣을 곳 | 제가 하는 일 |
|---|---|---|---|
| **나레이션 14줄** | `01.wav … 14.wav`, 48kHz 모노, 볼륨 정규화 **하지 말 것** | 아무 디렉터리 | `build.mjs --vo`로 타임코드에 배치 + -14 LUFS |
| **BGM** | wav/mp3 1개 + **라이선스 출처 한 줄** | 위와 같은 곳 | 나레이션 구간 덕킹해서 믹싱 |
| ~~SFX 3종~~ | — | — | **완료** — 코드로 합성해 채널 자산으로 넣었다 (`youtube/brand.md`) |

대본은 이미 있습니다 → `youtube/render/scenes/001-deepest-hole/narration.txt`
그 14줄을 그대로 TTS에 넣으면 됩니다. 보이스 스펙은 `youtube/voice.md`.

> **SFX는 완료됐습니다.** ffmpeg로 합성해 외부 소스가 없고, 피크를 -18 dBFS로 정렬했습니다.
> 회차 씬에 배치 시각만 적으면 `build.mjs`가 자동으로 얹습니다.

## 3. 정보로 주시면 제가 준비합니다

### 채널 (최초 1회)
| 항목 | 상태 | 비고 |
|---|---|---|
| 채널명 | **한계선** (제안) | 확정 or 변경 |
| 핸들 `@` | **미정** | 중복 확인이 필요해 사람이 정해야 함 |
| 채널 설명문 | 미작성 | 확정되면 제가 씁니다 |
| 프로필·배너 이미지 | **완료** | `youtube/render/out/brand/` — 규격·안전 영역 검산 완료 |

### 회차 업로드 설정 (유튜브가 물어보는 항목)
| 항목 | 제 제안 | 사장님 결정 필요 |
|---|---|---|
| 제목 | `12,262m에서 멈춘 이유는 장비가 아니었다` | 승인/변경 |
| 설명란 | `08-publish.md`에 작성 완료 (출처 포함) | 승인 |
| 공개 범위 | **일부공개로 먼저 올려 확인 후 공개** | 결정 |
| 예약 발행 | 평일 07:30 | 결정 |
| 카테고리 | 교육 | 결정 |
| 언어 / 자막 | 한국어 / `subtitles.srt` 업로드 | — |
| 아동용 여부 | **아동용 아님** | 확인 |
| 라이선스 | 표준 YouTube 라이선스 | — |
| 댓글 | 허용 (커뮤니티 대응이 이 팀의 절반) | — |
| 재생목록 | `숫자의 끝` 신규 생성 | 결정 |
| 고정 댓글 | `08-publish.md`에 초안 있음 | 승인 |

### ⚠️ 변경·합성 콘텐츠 공개 (반드시 확인)
유튜브는 **사실적으로 보이는** 사람·사건·장소를 AI로 만들었을 때 공개를 요구합니다.
- 이 영상은 **도해와 숫자뿐**이고 실사 장면이 없습니다 → **해당 없을 가능성이 높습니다.**
- 다만 **TTS 나레이션**이 들어가면 판단이 달라질 수 있습니다.
- **업로드 화면의 해당 문항을 직접 읽고 판단하세요.** 이건 제가 대신 판정하면 안 되는 항목입니다.
