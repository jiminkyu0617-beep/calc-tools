# 무료 공개 도구 조사 (2026-09)

**질문**: 구독·결제 없이, 유튜브에서 유행하는 AI 영상을 만들 수 있는 공개 코드·모델이 있는가?

**답**: 있다. 목소리·영상·음악·자동화 전 영역에 상업 이용 가능한 공개 모델이 있다.
다만 세 가지를 같이 알아야 한다.

1. **"코드는 무료"와 "돌릴 컴퓨터가 무료"는 다르다.** 영상 생성은 GPU가 필요하다.
   → 무료 GPU(Colab·Kaggle)로 해결된다.
2. **"공개됨"과 "상업 이용 가능"은 다르다.** 유명한 모델 중 수익화 채널에 쓰면 안 되는 게 섞여 있다.
3. **유행하는 "AI 자동 양산" 방식은 지금 유튜브가 수익을 끊는 바로 그 방식이다.** (아래 ⚠️)

---

## 이 작업 환경의 제약 (실측)

| 항목 | 상태 | 의미 |
|---|---|---|
| GPU | **없음** (CPU 4코어, RAM 15GB) | 영상 생성 모델은 여기서 못 돌린다 |
| HuggingFace | **차단** | 모델 가중치 대부분이 여기 있다 → 다운로드 불가 |
| ModelScope | **차단** | 중국계 모델 가중치 불가 |
| GitHub / pypi / npm | 접근 가능 | 코드는 받아진다 |

→ **HuggingFace만 허용되면 CPU용 한국어 TTS(Supertonic)는 여기서 바로 돌릴 수 있다.**
   영상 생성은 허용돼도 GPU가 없어 불가 — 무료 GPU 환경으로 가야 한다.

> 이 채널 용도(교양 나레이션)는 문제가 없지만, 사용 전 모델 카드의 제한 조항을 한 번 읽는다.

## 2. 영상 생성 (텍스트·이미지 → 영상)

| 모델 | 라이선스 | 필요 VRAM | 판정 |
|---|---|---|---|
| **Wan 2.2** (Alibaba) | **Apache 2.0** — 상업 제한 없음 | 5B: 8~12GB / 14B: 양자화 시 6~8GB | **1순위.** 무료 Colab T4(16GB)에서 돈다 |
| LTX-2.x (Lightricks) | 상업 가능 (연매출 $10M 미만 무료) | 32GB 이상 | 무료 GPU로는 벅차다 |
| HunyuanVideo 1.5 (Tencent) | **상업 이용 제한** | 약 14GB | ❌ 수익화 채널 부적합 |
| CogVideoX | 모델별 상이 | 16~24GB | 후순위 |

**이 채널에서의 용도는 `generative-policy.md`가 정한다** — 숫자·축·도해는 절대 생성하지 않고,
**코드로 못 그리는 물리 현상·질감에만** 쓴다. 001화 0:31 "암석이 엿처럼 늘어나는" 구간이 첫 후보다.

## ⚠️ 가장 중요한 것: 유튜브 "비진정성 콘텐츠" 정책

2025년 7월 15일, 유튜브가 "반복적 콘텐츠" 정책을 **"비진정성(inauthentic) 콘텐츠"**로 개명하고
**대량 생산·템플릿형 영상**을 명시적으로 수익화 대상에서 뺐다.

**표적이 되는 것**:
- 스톡 영상 슬라이드쇼 위에 TTS를 그대로 읽힌 영상
- 사람의 관여가 적어 **쉽게 대량 복제되는** 콘텐츠
- 건강·금융 같은 민감 주제를 AI 페르소나가 말하는 영상

**제재**: 경고 → 90일 수익 정지 → YPP 영구 퇴출 (3단계). 수천 개 AI 채널이 이미 정지됐다.

**그래서 MoneyPrinterTurbo 같은 "주제 한 줄 → 완성본" 도구를 쓰지 않는다.**
그게 지금 유행하는 방식이고, 유튜브가 지금 걸러내는 방식이다.

**이 채널이 안전한 이유** — 우연이 아니라 설계다:
| 정책이 문제 삼는 것 | 이 채널 |
|---|---|
| 스톡 영상 재활용 | 외부 소스 0건. 모든 화면을 직접 그린다 |
| 템플릿 반복 | 회차마다 도해를 새로 설계한다 (001화는 "자의 의미가 바뀌는" 구조) |
| 검증 없는 대량 생산 | 회차마다 출처 등급·검산·검수 게이트를 통과한다 |
| 사람의 관여 부족 | 기획·검수·피드백 루프에 사람이 판정한다 |

> 같은 기준에서 **생성 영상은 "양념"이지 "본체"가 아니어야** 한다. `generative-policy.md`와 일치한다.

**AI 공개 표기**: 합성 음성·AI 영상 사용 시 "변경·합성 콘텐츠" 체크가 필요하다는 해석과
사실적 재현에만 해당한다는 해석이 출처마다 갈린다. **업로드 화면 문항을 사람이 읽고 판단한다.**

## 무료 GPU

| 서비스 | 무료 한도 | 비고 |
|---|---|---|
| Google Colab | 주 약 15~30시간 T4(16GB), **고정 한도 없음** | 수요에 따라 변동 |
| Kaggle Notebooks | **주 30시간** GPU | 한도가 공개돼 있어 계획 세우기 쉽다 |

Wan 2.2 5B는 T4에서 돈다. 짧은 추상 컷(3~5초) 몇 개는 무료 한도 안에서 충분하다.
