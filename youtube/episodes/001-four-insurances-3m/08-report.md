# 08 성과 — (미발행)

발행 전이라 지표 없음. 발행 후 D+2, D+7에 `yt-analyst`가 채운다.

## 발행 시 수집할 것
- 조회수 / 노출수 / CTR
- **3초 유지율** (이 편의 단일 KPI, 목표 80%)
- 평균 시청 지속률, 재생 완료율
- 조회 대비 구독 전환
- 트래픽 소스 (Shorts 피드 / 검색 / 탐색)
- 계산기 페이지 유입 (설명란 링크 클릭)

## 이 편이 세울 기준선
1화이므로 이 편의 값이 **채널 중앙값의 시작점**이 된다.
2화부터는 이 숫자와 비교해 병목을 진단한다.
