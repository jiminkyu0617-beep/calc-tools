# 유튜브 크리에이터 에이전트 팀

목표: **구독자 100만**. 이 디렉터리는 그 목표를 향한 제작 조직을 코드로 고정한 것이다.
사람 팀에서 각자 다른 판단 기준을 갖는 9개 직무를, 서로 다른 시스템 프롬프트를 가진
에이전트 9개로 나눠 두었다. 정의 파일은 `.claude/agents/yt-*.md`.

## 왜 하나의 에이전트로 안 하는가

영상 제작이 실패하는 지점은 대부분 **한 사람이 자기 원고를 자기가 검수할 때** 생긴다.
각본가는 자기가 쓴 후킹이 약한 걸 못 보고, 편집자는 자기 컷의 지루함을 못 느낀다.
그래서 이 팀은 **생산 역할과 반대 역할을 물리적으로 분리**했다.

| 생산 | 그것을 깨는 반대 역할 |
|---|---|
| 각본가 (재미) | 검수관 (사실·정책·법적 리스크) |
| 패키저 (클릭 유도) | 검수관 (낚시성 판정 = 즉시 반려) |
| 연출가 (하고 싶은 그림) | 편집자 (실제 제작 공수·소스 확보 가능성) |
| 전체 (감) | 분석가 (리텐션 그래프 = 반박 불가 숫자) |

검수관과 분석가는 **반려 권한**을 갖는다. 총괄이 그걸 뒤집으려면 근거를 남겨야 한다.

## 파이프라인

한 편은 `youtube/episodes/<번호>-<슬러그>/` 안에서 아래 순서로 파일이 쌓인다.
**앞 단계 산출물 파일이 없으면 다음 단계는 시작하지 않는다.**

```
00-brief.md      전략     주제·타깃·이 편이 담당할 KPI
01-research.md   리서치   수요 근거 + 출처 목록 (링크·법령 조항까지)
02-script.md     각본     후킹/본문/CTA + 초 단위 타임코드
03-direction.md  연출     샷 리스트·화면 구성·톤·BGM 방향
04-edit.md       편집     컷 지시서·자막 파일·B롤 목록·렌더 사양
05-packaging.md  패키징   썸네일 시안 3안 + 제목 5안 + 선택 근거
06-qa.md         검수     체크리스트 판정 (PASS / 조건부 / 반려)
07-publish.md    퍼블리싱 최종 제목·설명·태그·챕터·공개 일시
08-report.md     분석     발행 후 48시간/7일 지표와 다음 편 지시
```

### 게이트 (총괄 PD가 판정)

- **G1 기획 게이트** — `01-research.md` 후. 수요 근거가 없으면 소재를 버린다.
- **G2 대본 게이트** — `02-script.md` 후. 후킹 3초에 "왜 봐야 하는지"가 없으면 반려.
- **G3 검수 게이트** — `06-qa.md`. 검수관 반려는 총괄이 뒤집을 수 없다(사실·법·정책 사안).
- **G4 발행 게이트** — 패키징 CTR 예측이 채널 중앙값 이하면 제목·썸네일만 재작업.

## 채널 컨셉

`youtube/channel-brief.md` 참조. 이 파일 하나만 바꾸면 팀 전체가 다른 니치로 움직인다.
에이전트 정의는 니치에 종속되지 않게 썼다.

## 사용법

```
/yt-episode 실업급여 상한액 2026년 인상분
```
총괄 PD가 파이프라인을 처음부터 끝까지 돌린다. 개별 호출도 가능하다:
"yt-packager 에이전트로 3화 썸네일 다시 뽑아줘"

## 표본 회차

`youtube/episodes/001-four-insurances-3m/` 에 파이프라인을 끝까지 돌린 결과가 들어 있다.
9개 파일이 어떻게 이어지는지, 검수관이 왜 **조건부**를 냈는지(1차 출처 등급 문제)를
그대로 볼 수 있다. 새 회차를 만들 때 이 디렉터리를 형식 기준으로 삼는다.

## 100만까지의 단계

| 단계 | 구독자 | 이 구간의 유일한 과제 | 팀 운영 방식 |
|---|---|---|---|
| 0→1천 | 발견 | **어떤 포맷이 먹히는지** 찾기 | 주 5편 쇼츠, 포맷 4종 병렬 실험 |
| 1천→1만 | 반복 | 먹힌 포맷 1개를 **양산** | 승리 포맷 고정, 주 7편, 롱폼 주 1편 시작 |
| 1만→10만 | 확장 | 쇼츠 시청자를 **롱폼·구독으로** 이동 | 쇼츠=유입, 롱폼=체류. 시리즈물 도입 |
| 10만→100만 | 시스템 | 개인 감각을 **재현 가능한 공정으로** | 분석가 주도 주간 실험, 외주 가능한 지시서화 |

각 구간의 병목이 다르므로 **전략 에이전트가 단계 전환을 선언**하고,
그때 각본·연출의 기준선을 갈아끼운다. 전 단계 기준을 다음 단계에서 계속 쓰는 것이
성장이 멈추는 가장 흔한 원인이다.

## 지표 기준선

아래는 업계에서 통용되는 출발선이며 **채널 데이터가 쌓이면 자기 채널 중앙값으로 교체**한다.
남의 평균을 끝까지 목표로 삼지 않는다.

| 지표 | 쇼츠 | 롱폼 |
|---|---|---|
| 후킹 구간 유지율 | 3초 시점 80%+ | 30초 시점 65%+ |
| 평균 시청 지속률 | 70%+ (또는 재생 완료율 60%+) | 45%+ |
| 노출 클릭률 (CTR) | — (피드 구조상 무의미) | 5%+ |
| 조회 대비 구독 전환 | 0.3%+ | 1%+ |
